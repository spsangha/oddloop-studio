# Poly Haven model library (CC0, 1k glTF), index for the Kinda Wild kit

Owner 2026-11-23: "If poly haven we can use and it's better than us and free and it use less credits we can use it" and "Yes whatever we need in the future. So we can save time".
Licence: CC0, commercial use, no credit needed (https://polyhaven.com/license). Source page of any model: https://polyhaven.com/a/<id>.
STATUS: every model below is DOWNLOADED but NOT FITTED. Fitting (scale check, floor contact, placement in a set, hand grip if held) is done per SET in one batch with one brief (kit/brief_template.md), never while a character build is open. Load with kwsets.gltf_fit(c, "<id>", loc, rz, (axis, metres)). When a model is fitted, change its Status cell to the set name and date.
Dimensions are the catalogue's bounding box in metres (x, y, z); check them in the fit, several are sets of objects laid out in a row.
